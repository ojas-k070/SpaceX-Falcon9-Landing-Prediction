# SpaceX Falcon 9 First-Stage Landing Analysis

A student data-science capstone project exploring Falcon 9 landing outcomes using public SpaceX launch data and the IBM Skills Network course datasets.

## Project objectives
- Collect and inspect launch data from the course-provided SpaceX JSON dataset.
- Scrape historical launch tables from Wikipedia and save the extracted tables for inspection.
- Clean data, handle missing payload mass, encode categorical features, and define a binary landing-success target.
- Explore launch outcomes with charts and SQL queries.
- Map geospatial launch records with Folium.
- Build an interactive Plotly Dash dashboard.
- Compare Logistic Regression, SVM, Decision Tree, and KNN classifiers using cross-validation and a held-out test set.

## Repository contents
| File | Purpose |
|---|---|

## Setup
Recommended: Python 3.10 or 3.11 in a virtual environment.

### Windows PowerShell
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter notebook
```

If you already have Python installed, create the environment with `python -m venv .venv` instead.

## Recommended execution order
1. `data_collection.ipynb`
2. `web_scraping.ipynb`
3. `data_wrangling.ipynb`
4. `eda_visualization.ipynb`
5. `eda_sql.ipynb`
6. `folium_map.ipynb`
7. `predictive_analysis.ipynb`
8. Run the dashboard from a terminal: `python plotly_dash.py`

The notebooks use course-hosted datasets. An internet connection is required. If a dataset URL or source webpage changes, inspect the response and update the source accordingly.

## Dashboard
After running `python plotly_dash.py`, open `http://127.0.0.1:8050` in your browser. The dropdown filters launch site; the range slider filters payload mass. The charts are generated from the loaded dataset.
